\section{Definitions}

We propose the following addition to the module language syntax:

\begin{figure}[h]
    \begin{center}
        \begin{tabular}{r c ll}
            $P$         & ::= & $X$                                                               \\
                        & |   & $P.X$                                                             \\[3mm]
            $\Pi$       & ::= & $\epsilon$                                                        \\
                        & |   & $P$                                                               \\[3mm]
            $M$         & ::= & $X$                                                               \\
                        & ::= & $\Elixir.P[\overline{\tx = t}]$                                   \\[3mm]
            $\Next$     & ::= & $N$                                                               \\
                        & |   & $\tx$                                                             \\[3mm]
            $\Gammatop$ & ::= & $\overline{P : \Moddecl}$       & \color{Gray} module environment \\[3mm]
            $\Gammabot$ & ::= & $\overline{D}$
        \end{tabular}
    \end{center}
    \caption{Some addition to the module language syntax}
\end{figure}

$\Gammatop$ is the module environment. It contains \texttt{defmodule} declarations. The path of submodules is flattened.

$\Gammabot$ is the local environment. It cannot contain \texttt{defmodule} declarations.

Empty environments will be denoted $\emptyenv$. \\

We consider behavior environments and declaration lists as partial functions
from $\BX$ and $\Next$ to $\Beh$ and $D$, respectively.
If the name appears multiple time in the list, the right-most occurrence is returned, as one would expect.

Similarly, module environments are partial functions over $P$.

\section{Wellformedness}

We introduce wellformedness judgements:

\begin{figure}[H]
    \begin{center}
        \begin{tabular}{lrll}
            Behavior environments: &                                & $\vdash \Sigma$                      \\[2mm]
            Global environments:   & $\Sigma$                       & $\vdash \Gammatop$                   \\[2mm]
            Local environments:    & $\Sigma; \Gammatop$            & $\vdash \Gammabot$    & \color{Gray} \\[2mm]
            Declaration lists:     & $\Sigma; \Gammatop; \Gammabot$ & $\vdash \overline{D}$ & \color{Gray} \\[2mm]
            Type:                  & $\Sigma; \Gammatop; \Gammabot$ & $\vdash T$
        \end{tabular}
    \end{center}
\end{figure}

\subsection{Behavior environments}

\[
    \begin{prooftree}
        \infer0{ \vdash \emptyenv }
    \end{prooftree}
    \qquad
    \begin{prooftree}
        \hypo{ \vdash \Sigma }
        \hypo{ \Sigma; \emptyenv; \overline{\tx : \star} \vdash \{ \overline{D} \} }
        \infer2{ \vdash \Sigma, \BX : \Lambda (\overline{\tx : \star}).\{\overline{D}\} }
    \end{prooftree}
\]

This rule also requires the $\overline{\tx}$ are pairwise distinct.

Because we use $\epsilon$ as the path in the rule above, the behavior will not be
able to declare submodules (see the section about wellformedness of declaration lists). This is intended.

\subsection{Global environments}
\[
    \begin{prooftree}
        \hypo { \vdash \Sigma }
        \infer1 { \Sigma \vdash \emptyenv }
    \end{prooftree}
\]

\[
    \begin{prooftree}
        \hypo{\Sigma \vdash \Gammatop}
        \hypo{ \Sigma; \Gammatop; \overline{\tx : \star} \vdash \{ \overline{D} \}_{\overline{\BX[\overline{\tx' = t}]}} }
        \infer2{ \Sigma \vdash \Gammatop, P : \Moddecl }
    \end{prooftree}
\]

\subsection{Local type environments}

\[
    \begin{prooftree}
        \hypo{ \Sigma \vdash \Gammatop}
        \infer1{ \Sigma; \Gammatop \vdash \emptyenv }
    \end{prooftree}
\]

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash t }
        \infer1{ \Sigma; \Gammatop \vdash \Gammabot, X : t }
    \end{prooftree}
\]
\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop \vdash \Gammabot }
        \infer1{ \Sigma; \Gammatop \vdash \Gammabot, \tx : \star }
    \end{prooftree}
\]
\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash t }
        \infer1{ \Sigma; \Gammatop \vdash \Gammabot, \tx : [= t] }
    \end{prooftree}
\]
\[
    \begin{prooftree}
        \hypo{ \overline{T} \neq \emptyset }
        \hypo{ \overline{\Pi; \Sigma; \Gammatop; \Gammabot \vdash T} }
        \infer2{ \Pi; \Sigma; \Gammatop \vdash \Gammabot, x : \bigcap \overline{T} }
    \end{prooftree}
\] \\

\subsection{Declaration list}

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop \vdash \Gammabot }
        \infer1{ \Sigma; \Gammatop; \Gammabot \vdash \emptyenv }
    \end{prooftree}
\]

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot, D \vdash \overline{D'} }
        \infer1{ \Sigma; \Gammatop; \Gammabot \vdash D, \overline{D'} }
    \end{prooftree}

\subsection{Pretypes}

\[
    \begin{prooftree}
        \hypo { \Sigma; \Gammatop \vdash \Gammabot }
        \infer1{ \Sigma; \Gammatop; \Gammabot \vdash \tau }
    \end{prooftree}
    \qquad
    \begin{prooftree}
        \hypo{ \overline{ \Sigma; \Gammatop; \Gammabot \vdash t}}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash t'}
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash (\overline{t}) \rightarrow t' }
    \end{prooftree}
    \qquad
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop \vdash \Gammabot }
        \hypo{ \overline{ \Sigma; \Gammatop; \Gammabot \vdash t} }
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash  \%\{ \overline{k: t} \} }
    \end{prooftree}
\]

Keys $\overline{k}$ also need to be pairwise distinct. \\

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash t }
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash t' }
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash  t \vee  t' }
    \end{prooftree}
    \qquad
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash t }
        \infer1{ \Sigma; \Gammatop; \Gammabot \vdash  \lnot t }
    \end{prooftree}
\]

\[
    \begin{prooftree}
        \hypo{  \Sigma; \Gammatop \vdash \Gammabot }
        \hypo{ \tx \in \dom(\Gammabot) }
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash \tx }
    \end{prooftree}
    \qquad
    \begin{prooftree}
        \hypo {  \Sigma; \Gammatop \vdash \Gammabot }
        \hypo { \Sigma(\BX) = \BX : \Lambda \left( \overline{\tx : \star} \right) \{\overline D \}}
        \hypo { \overline { \Sigma; \Gammatop; \Gammabot \vdash t} }
        \infer3{  \Sigma; \Gammatop; \Gammabot \vdash \BX [\overline{\tx = t}]  }
    \end{prooftree}
\]

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash M : \{ \tx : \star \} }
        \infer1{ \Sigma; \Gammatop; \Gammabot \vdash M.\tx }
    \end{prooftree}
\]

In the above rule, $\Sigma; \Gammatop; \Gammabot \vdash M : \{ \tx : \star \}$ is a typing judgement.
Thanks to subtyping, $\{ \tx : \star \}$ may not be exactly the type associated with $M$ in $\Gammatop$ or $\Gammabot$.


\subsection{Singleton module type}

\[
    \begin{prooftree}
        \hypo { \Sigma; \Gammatop \vdash \Gammabot }
        \hypo { \Gammatop(P) = X : \Moddecl[\tx] [\overline{D}][\BX][\tx'][t']}
        \hypo { \overline{\Sigma; \Gammatop; \Gammabot \vdash t} }
        \infer3{ \Sigma; \Gammatop; \Gammabot \vdash \langle \Elixir.P[\overline{\tx = t}] \rangle }
    \end{prooftree}
\]

\[
    \begin{prooftree}
        \hypo {\Gammabot(X) = X : t }
        \hypo { \Sigma; \Gammatop; \Gammabot \vdash t \preceq \mod }
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash \langle X \rangle }
    \end{prooftree}
\]

In the rule above, $X$ is a local variable (in practice, a function parameter).
As a result, it must have an already instantiated type (parametric modules are not types).
That's why we don't allow instantiating $X$ again.

\subsection{Types}

We define the function $\name(D)$ as $\name: \left\{\begin{array}{ll}
        X : t                    & \mapsto X   \\
        x : \bigcap \overline{T} & \mapsto x   \\
        \tx : \star              & \mapsto \tx \\
        \tx : [=t]               & \mapsto \tx
    \end{array}\right.$  \\[3mm]

\[
    \begin{prooftree}
        \hypo { \color{gray} \; \Sigma; \Gammatop; \Gammabot \vdash \overline{N : T}  }
        \hypo { \Sigma; \Gammatop; \Gammabot, \overline{N : T} \vdash  T' }
        \infer2{ \Sigma; \Gammatop; \Gammabot  \vdash (\overline{N : T}) \rightarrow T' }
    \end{prooftree}
\]
We also require that $\overline{N}$ are pairwise distinct. \\


\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop \vdash \Gammabot }
        \infer1{ \Sigma; \Gammatop; \Gammabot \vdash \{ \} }
    \end{prooftree}
\]
\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot, D \vdash \{\overline{D'} \}}
        \hypo{ \name(D) \notin \dom(\Gammabot) }
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash \{ D, \overline{D'} \} }
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash \{\overline{D} \}}
         \hypo{\overline{\Sigma; \Gammatop; \Gammabot \vdash \BX[\overline{\tx = t}]} }
        \hypo{ \forall i \neq j. \; \overline{\BX}^i \# \overline{\BX}^j }
      \hypo{\overline{\Sigma; \Gammatop; \Gammabot \vdash \{\overline{D}\} \preceq  \Sigma(\BX)[\overline{\tx := t}]}}
        \infer4{ \Sigma; \Gammatop; \Gammabot \vdash  \{ \overline{D} \}_{\overline{\BX[\overline{\tx = t}]}}}
    \end{prooftree}
\] \\


where, assuming $\Sigma(\BX) = \BX : \Lambda (\overline{\tx : \star}) \{\overline{D}\}$ and
$\Sigma(\BX') = \BX' : \Lambda (\overline{\tx' : \star}) \{\overline{D'}\}$:
\begin{itemize}
    \item $\BX \# \BX'$ if and only if $\BX \neq \BX'$ and $\dom(\overline D) \cap \dom(\overline{D'}) = \emptyset$
    \item $\Sigma(\BX)[\overline{\tx := t}] = \{ \overline{D[\overline{t/\tx}]} \}$
\end{itemize}

This last rule is only useful when $\overline{\BX}$ is not empty.

\section{Subtyping}

Elixir's semantic subtyping will be denoted $ t \vartriangleleft t'$.

We define the syntactic subtyping judgement: $\Sigma; \Gammatop; \Gammabot \vdash \bigcap \overline{T} \preceq \bigcap \overline{T'}$.
We will denote $\bigcap \overline{T} \simeq \bigcap \overline{T'}$ when both $\bigcap \overline{T} \preceq \bigcap \overline{T'}$ and $\bigcap \overline{T'} \preceq \bigcap \overline{T}$ hold.

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop \vdash \Gammabot }
        \hypo{ t \vartriangleleft t' }
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash t \preceq t' }
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash \{ \overline{D} \} \cap \bigcap \overline{\BX[\overline{\tx = t}]} \preceq \{ \overline{D'} \} \cap \bigcap \overline{\BX'[\overline{\tx' = t'}]}}
        \infer1{ \Sigma; \Gammatop; \Gammabot \vdash \{ \overline{D} \}_{\overline{\BX[\overline{\tx = t}]} } \preceq \{ \overline{D'} \}_{\overline{\BX'[\overline{\tx' = t'}]} } }
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash \{ \overline{D} \}_{\overline{\BX[\overline{\tx = t}]} }}
        \infer1{ \Sigma; \Gammatop; \Gammabot \vdash \{ \overline{D} \}_{\overline{\BX[\overline{\tx = t}]} } \preceq \bigcap \overline{\BX[\overline{\tx = t}]} }
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop \vdash \Gammabot }
        \hypo{ \overline{\Sigma; \Gammatop; \Gammabot \vdash T} }
        \hypo{ \forall j. \exists i. \; \Sigma; \Gammatop; \Gammabot \vdash \overline{T}^i \preceq \overline{T'}^j }
        \infer3{ \Sigma; \Gammatop; \Gammabot \vdash \bigcap \overline{T} \preceq \bigcap \overline{T'}}
    \end{prooftree}
\] \\

The other direction might (or might not) be useful later:

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash t }
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash t' }
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash t \cap t' \preceq t \wedge t' }
    \end{prooftree}
\] \\

\paragraph{Base case}

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash \{ \overline{D} \} }
        \infer1{ \Sigma; \Gammatop; \Gammabot \vdash \{ \overline{D} \} \preceq \{ \} }
    \end{prooftree}
\]

\paragraph{Skip left declarations}

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot, \tx : \star  \vdash \{ \overline{D} \} \preceq \{\overline{D'}\} }
        \hypo{ \tx \notin \Gammabot \cup  \dom(\overline{D'}) }
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash \{ \tx : \star, \overline{D} \} \preceq \{ \overline{D'} \} }
    \end{prooftree}
\]

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash \{ \overline{D}[t/\tx] \} \preceq \{\overline{D'}\} }
        \infer1{ \Sigma; \Gammatop; \Gammabot \vdash \{ \tx : [= t], \overline{D} \} \preceq \{ \overline{D'} \} }
    \end{prooftree}
\]

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash \{ \overline{D} \} \preceq \{\overline{D'}\} }
        \infer1{ \Sigma; \Gammatop; \Gammabot \vdash \{ x : \bigcap \overline{T}, \overline{D} \} \preceq \{ \overline{D'} \} }
    \end{prooftree}
\]

In practice we will only use "skip" if the declaration does not appear in $\dom(\overline{D'})$, otherwise
we would get stuck later.

\section{Expressions}

We define the expression typing judgement: $P; \Sigma; \Gammatop; \Gammabot \vdash E : \bigcap \overline{T}$.

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash E : \bigcap \overline{T} }
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash \bigcap \overline{T}\preceq \bigcap \overline{T'} }
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash E: \bigcap \overline{T'}}
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo{ \Sigma; \Gammatop \vdash \Gammabot }
        \hypo{ \Gammabot(x) = x : \bigcap \overline{T} }
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash  x : \bigcap \overline{T} }
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo { \Sigma; \Gammatop; \Gammabot \vdash \%\{ \overline{k : t} \} }
        \hypo { \overline{\Sigma; \Gammatop; \Gammabot \vdash E : t} }
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash \%\{\overline{k = E}\} : \%\{\overline{k : t}\} }
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo { \Sigma; \Gammatop; \vdash \Gammabot }
        \hypo { \overline{ \Sigma; \Gammatop; \Gammabot \vdash (\overline{t}) \rightarrow t'} }
        \hypo { \overline{ \Sigma; \Gammatop; \Gammabot, \overline{x : t} \vdash E: t'} }
        \infer3{ \Sigma; \Gammatop; \Gammabot \vdash \bigwedge \overline{(\overline{t}) \rightarrow t'} \text{ fn } \overline{x} \rightarrow E : \bigwedge \overline{ (\overline{t}) \rightarrow t'} }
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo { \Sigma; \Gammatop; \vdash \Gammabot }
        \hypo { \overline{\Sigma; \Gammatop; \Gammabot \vdash (\overline{N : T}) \rightarrow T'} }
        \hypo { \overline{ \Sigma; \Gamma, \overline{N : T} \vdash E: T'} }
        \infer3{ \Sigma; \Gammatop; \Gammabot \vdash \bigcap \overline{(\overline{N : T}) \rightarrow T'} \text{ fn } \overline{N} \rightarrow E : \bigcap \overline{(\overline{N : T }) \rightarrow T'} }
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo { \Sigma; \Gammatop; \Gammabot \vdash E : T }
        \hypo { \Sigma; \Gammatop; \Gammabot, N : T \vdash E' : T' }
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash \text{let } N = E \text{ in } E' : T' }
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo { \Sigma; \Gammatop; \Gammabot \vdash \overline{N : T_\downarrow} }
        \hypo { \Sigma; \Gammatop; \Gammabot \vdash E : (\overline{N' : T}) \rightarrow T'}
        \infer2{ \Sigma; \Gammatop; \Gammabot \vdash E(\overline{N}) : T'[\overline{N'/N}] }
    \end{prooftree}
\] \\

where $\overline{T_\downarrow}^i = \overline{T}^i[\overline{N'/N}^{0..i}]$ and the slicing operator
$0..i$ takes elements up to index $i$ (excluded).

\[

    \end{prooftree}
\] \\

    \end{prooftree}
\]

\section{Bindings}

We define the notation $\Gammatop[P \texttt{+=} D]$ as:

\begin{figure}[H]
    \begin{tabular}{lll}
        $\left(\Gammatop, P : \Moddecl\right)[P \texttt{+=} D']$  & = $\Gammatop, P : \Moddecl[\tx][\overline{D}, D']$ \\[3mm]
        $\left(\Gammatop, P' : \Moddecl\right)[P \texttt{+=} D']$ & $= \Gammatop[P \texttt{+=} D'], P' : \Moddecl$     \\[3mm]
        undefined otherwise
    \end{tabular}
    \caption{Notation $\Gammatop[\pi \texttt{+=} D']$}
\end{figure}


We define the typing judgement for bindings: $\Pi; \Sigma; \Gammatop; \Gammabot \vdash \overline{B} : \{ \overline{D} \}$.

\[
    \begin{prooftree}
        \hypo{ x \notin \dom(\Gammabot) }
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash v: \bigcap \overline{T} }
        \hypo{ P; \Sigma; \Gammatop\left[P \texttt{+=} x : \bigcap \overline{T}\right]; \left(\Gammabot, x : \bigcap \overline{T}\right) \vdash \overline{B} : \{\overline{D}\} }
        \infer3{ P; \Sigma; \Gammatop; \Gammabot \vdash x = v, \overline{B} : \{ x : \bigcap \overline{T}, \overline{D} \} }
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo{ x \notin \dom(\Gammabot) }
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash v: \bigcap \overline{T} }
        \hypo{ P; \Sigma; \Gammatop; \left(\Gammabot, x : \bigcap \overline{T}\right) \vdash \overline{B} : \{\overline{D}\} }
        \infer3{ P; \Sigma; \Gammatop; \Gammabot \vdash \private x = v, \overline{B} : \{ \overline{D} \} }
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo{ \tx \notin \dom(\Gammabot) }
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash t }
        \hypo{ P; \Sigma; \Gammatop\left[P \texttt{+=} \tx : [= t]\right]; \left(\Gammabot, \tx : [= t]\right) \vdash \overline{B} : \{\overline{D}\} }
        \infer3{ P; \Sigma; \Gammatop; \Gammabot \vdash \type \tx = t, \overline{B} : \{ \tx : [= t], \overline{D} \} }
    \end{prooftree}
\] \\

\[
    \begin{prooftree}
        \hypo{ \tx \notin \dom(\Gammabot) }
        \hypo{ \Sigma; \Gammatop; \Gammabot \vdash t }
        \hypo{ P; \Sigma; \Gammatop\left[P \texttt{+=} \tx : \star\right]; \left(\Gammabot, \tx : [= t]\right) \vdash \overline{B} : \{\overline{D}\} }
        \infer3{ P; \Sigma; \Gammatop; \Gammabot \vdash \opaque \tx = t, \overline{B} : \{ \tx : \star, \overline{D} \} }
    \end{prooftree}
\] \\


\[
    \begin{prooftree}
        \hypo{ \Pi.X; \Sigma; \left(\Gammatop, \Pi.X : \Lambda (\overline{\tx : \star}). \{\}\right); \overline{\tx : \star} \vdash \overline{B} : \{\overline{D}\} }
        \hypo{ \Sigma; \Gammatop'; \overline{\tx : \star} \vdash \{\overline{D}\}_{\overline{\BX[\overline{\tx' = t}]}} }
        \hypo{ \Pi; \Sigma; \Gammatop'; \Gammabot \vdash \overline{B'} : \{\overline{D'}\} }
        \infer3{ \Pi; \Sigma; \Gammatop; \Gammabot \vdash X : \Lambda (\overline{\tx : \star}). \{\overline{B}\}_{\overline{\BX[\overline{\tx'  = t}]}}, \overline{B'} : \{ \overline{D'} \} }
    \end{prooftree}
\] \\

where $\Gammatop' = \Gammatop, \Pi.X :\Moddecl$

By abuse of notation, we write $\Pi.X$ and, when $\Pi$ is the empty path, we consider
that $\epsilon.X$ just denotes $X$. This way, we don't have to duplicate the rule above.
